# 🚀 TaskGenie – AI Powered Task Extraction Dashboard

TaskGenie is a modern AI-powered productivity dashboard that extracts actionable tasks from meeting notes, conversations, and raw text using AI.

It automatically detects:

* ✅ Tasks
* 👤 Assignees
* 📅 Deadlines
* ⚡ Priorities
* 📊 Confidence scores

and displays them inside a beautiful SaaS-style dashboard.

---

# ✨ Features

## 🤖 AI Task Extraction

Paste meeting notes or conversations and instantly generate structured tasks.

### Extracts:

* Task title
* Assigned person
* Assigned by
* Deadline
* Priority
* Confidence level

---

## 📊 Dashboard Analytics

Modern analytics dashboard with:

* Total tasks
* Completed tasks
* Pending tasks
* Overdue tasks

---

## 🎨 Modern SaaS UI

Inspired by modern productivity apps.

### Includes:

* Dark & Light mode
* Premium sidebar
* Interactive topbar
* Animated task cards
* Responsive layout
* Toast notifications
* Cartoon avatars

---

## 📅 Smart Deadline System

Understands natural language deadlines:

* Tomorrow

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/AI-Task-Extractor-Tool.git
```

---

## 2️⃣ Install Dependencies

### Frontend

```bash
cd frontend
npm install
```

### Backend

```bash
cd backend
npm install
```


---

# ▶️ Run Project

## Start Backend

```bash
npm run dev
```

## Start Frontend

```bash
npm start
```
